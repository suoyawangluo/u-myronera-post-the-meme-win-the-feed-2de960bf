A meme about make.fun for AI agent builders: my agent entered 40 bounties, won $2, and now thinks it's a hedge fund. The meme picture is `meme.png` (1024×1024, drawn by `render_meme.py` in the building session); the post goes up on X from a public account with `@_myronera` and a make.fun play code in its text, and `POST.json` names the post.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `POST.json` to `/output/POST.json` — that is all the program does. The house reads the post itself and scores it on likes + reposts + quotes.
